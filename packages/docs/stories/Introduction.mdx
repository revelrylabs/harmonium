<h2 className="intro-section-header">Why Harmonium?</h2>

<div className="intro-grid">
  <div className="intro-card">
    <h3>Zero Runtime Styling</h3>
    <p>CSS Modules at build time — no Emotion, no styled-components, no JS style injection. RSC compatible out of the box.</p>
  </div>
  <div className="intro-card">
    <h3>Theme with Plain CSS</h3>
    <p>Override CSS custom properties in a stylesheet. No providers, no JS theme objects, no build plugins required.</p>
  </div>
  <div className="intro-card">
    <h3>Accessible by Default</h3>
    <p>Built on Base UI primitives with WCAG 2.1 AA compliance, keyboard navigation, and focus management baked in.</p>
  </div>
  <div className="intro-card">
    <h3>Typed Enum Props</h3>
    <p><code>variant="primary"</code> not <code>className="btn-primary"</code>. Full TypeScript autocomplete for every prop and variant.</p>
  </div>
  <div className="intro-card">
    <h3>LLM-Friendly</h3>
    <p>Ships <code>llms.txt</code>, <code>CLAUDE.md</code>, and <code>AGENTS.md</code> so AI coding tools generate correct Harmonium code on the first try.</p>
  </div>
  <div className="intro-card">
    <h3>Tiny Footprint</h3>
    <p>~20 KB gzipped for all 50 components (JS + CSS). Lighter than most alternatives ship for a single component.</p>
  </div>
</div>

<h2 className="intro-section-header">Theming</h2>

Override design tokens with plain CSS — no build tools required:

```css
:root {
  --harmonium-color-brand-primary: #E91E63;
  --harmonium-color-brand-secondary: #9C27B0;
  --harmonium-radius-md: 8px;
  --harmonium-font-family-sans: 'Inter', sans-serif;
}
```

Dark mode:

```css
[data-theme="dark"] {
  --harmonium-color-bg: #1a1a1a;
  --harmonium-color-text: #f0f0f0;
  --harmonium-color-surface: #2d2d2d;
  --harmonium-color-border: #404040;
}
```
